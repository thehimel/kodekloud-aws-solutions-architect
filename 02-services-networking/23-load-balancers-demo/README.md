## ELB Types

![img_6.png](assets/img_6.png)

### Classic Load Balancers (CLB)

* You cannot use multiple SSL certificates with a classic load balancer.
* Combining other reasons, CLB is outdated, and should not be used.
* Either use Application Load Balancers or Network Load Balancers.

![img_7.png](assets/img_7.png)

### Application Load Balancers (ALB)

* By default, the traffics between the load balancer and the target groups are not encrypted.
* You can use SSL certificate on the instance to make the traffic encrypted.
